# Windows nanoserver  container demos for developers

[![codecov](https://codecov.io/gh/zippy1981/windows-nano-demos/graph/badge.svg)](https://codecov.io/gh/zippy1981/windows-nano-demos)

I'm experimenting with windows containers and I'm putting the results here.

## Containers

Each image is built and smoke-tested for Windows Server ltsc2019, ltsc2022 and ltsc2025 (ADR 0008), and published to Docker Hub as `zippy1981/<image>:<version>` by the [image refresh workflow](.github/workflows/image-refresh.yml).

- **CI** shows the latest run of the image's workflow on `main`. It goes red if any Windows version fails.
- The **ltsc** columns show two badges for that Windows version:
  - **Build** says whether that version passed in the latest run on `main` that finished its legs. The [OS badges workflow](.github/workflows/os-badges.yml) updates it after every image run.
  - **Size** is the size of the published image, linked to its tags on Docker Hub. "repository or tag not found" means it hasn't been published yet.
